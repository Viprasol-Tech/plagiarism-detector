# Plagiarism Detector

Detect plagiarism and similarity

## Features

- Zero external dependencies (stdlib only)
- Easy-to-use CLI interface
- Professional Python implementation
- MIT licensed

## Installation

```bash
pip install -e .
```

Or clone and install:

```bash
git clone https://github.com/Viprasol-Tech/plagiarism-detector
cd plagiarism-detector
pip install -e .
```

## Usage

### Python

```python
from plagiarism_detector import PlagiarismDetector

result = PlagiarismDetector.process("data")
print(result)
```

### CLI

```bash
python -m plagiarism_detector "your input here"
```
